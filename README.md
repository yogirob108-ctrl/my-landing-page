# 8 Lakes Tours

Mongolia horse-riding trekking adventure website.

This repository currently powers the first Horse Emoji Adventures / 8 Lakes Tours landing page while Henry and Robert test the GitHub → PR → Vercel deployment workflow.

## Development

Run the local development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Stack

- Next.js
- TypeScript
- Vercel deployment
